🏁 마라톤 코스도 제작기

카카오맵 기반 · 참가자용/관리자용 코스도 생성

1. 카카오맵 설정

라인 편집 모드의 🛣 도로 보정에 사용됩니다. 브라우저에서 직접 호출하므로 CORS가 막히면 동작하지 않을 수 있고, 키가 파일에 저장되니 외부 배포용 파일에는 넣지 마세요. 키가 없어도 〰 선 다듬기는 그냥 씁니다.

2. 코스 구성

120 m
사용 스위치로 없는 종목은 비활성화하세요.
겹침 설정 — 자동: 겹치는 구간 시설을 이 코스 km로 자동 환산 / 일부: 겹치는 구간만 자동 / 독립: 이 코스 전용 시설만.
코스가 같은 길인데 시설이 안 잡히면 인식 반경을 넓히세요(GPX 궤적이 서로 떨어져 있을 때).
반환 지점은 코스 카드의 ↩ 반환점 버튼에서 km를 직접 지정할 수 있습니다(왕복 코스는 자동 감지값 제공). 라인 편집 중에는 복편이 자동으로 벌어져 따로 잡을 수 있습니다.

3. 대회 운영 정보

시설별 운영 시간(선두 도착 ~ 후미 통과)이 자동 계산됩니다. 종목별 참가 인원은 코스 카드의 ✎ 옆 인원 칸에 입력하세요.

지도 우클릭 → 시설 배치 · 마커 클릭 → 수정/이동/삭제

6. 관리자용 물자 항목

항목별 1인당 계수를 넣어두면 참가 인원 기준으로 급수대 수량을 자동 산정할 수 있습니다.

10. ☁ 클라우드 저장 (Firebase)

미연결
준비 ① Firebase 콘솔에서 프로젝트 생성 → 웹 앱 등록 후 firebaseConfig 복사
② Authentication → 이메일/비밀번호 켜고 사용할 계정 추가
③ Firestore 데이터베이스 생성 후 규칙 저장 (아래 규칙 보기)
④ 이 파일을 Firebase Hosting에 올리고, 그 주소를 카카오 개발자 콘솔 플랫폼에도 등록
firebaseConfig는 파일에 들어 있어 매번 붙여넣지 않아도 됩니다. 한 번 로그인하면 같은 브라우저에서는 로그인 상태가 유지됩니다. GPX 좌표는 압축 저장되어 문서 1MiB 제한 안에 들어갑니다.

🗺 코스 지도

📍 새 위치를 지도에서 클릭하세요 (ESC 취소)
✏ 코스 라인 편집 50 m

⛰ 고저도 마우스를 올리면 지점별 고도·경사와 지도 위치가 표시됩니다

📋 코스 시설 안내 명칭·비고 칸을 클릭하면 바로 수정됩니다

⏱ 구간별 통과 예상 시각 간격

출발 시각과 페이스 밴드 기준 예상 통과 시각입니다(제한시간 열 = 코스별 제한시간 평균 페이스). 관리자용 코스도에만 포함됩니다.

🧰 물자 배정표

칸에 수량을 직접 입력하면 즉시 저장됩니다. 각 칸의 체크박스로 그 시설에서 해당 물자를 쓸지 끄고 켤 수 있고(끄면 자동 산정·합계에서 제외), 열 제목을 누르면 표시된 시설 전체에 일괄 적용됩니다. 시설명 옆 ⚙로 한 시설의 종류를 모아서 선택할 수도 있습니다. 자동 산정은 (그 지점을 지나는 종목들의 참가 인원 합) × (물자 항목의 1인당 계수)로 채웁니다. 관리자용 코스도에만 표시됩니다.
